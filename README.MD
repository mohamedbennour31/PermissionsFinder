PermissionsFinder

A privacy and security scanner for Android devices that inspects installed applications and system posture.
What It Scans For

    Foreground Camera, Mic & Location: Detects access to camera, microphone, and foreground GPS locations.

    Background Location Tracking: Flags apps capable of tracking device location in the background.

    SMS & Contacts: Identifies access to call logs, text messages, and contact lists.

    Accessibility Services: Flags enabled accessibility permissions that monitor user interactions.

    Debug Build Flags: Identifies non-production apps compiled with active debug parameters.

    Device Security Posture: Evaluates system-wide security settings (Root status and Screen Lock enforcement).

How to Use It

    Launch the App: Open PermissionsFinder on your Android device.

    Review System Posture: Check top-level security indicators, including root status and lock screen security.

    Filter Risks: Tap any category in the Security Matrix to filter installed apps by target risk flags.

    Inspect & Remediate: Review detected permission risks and follow the provided step-by-step instructions to adjust your Android settings.
